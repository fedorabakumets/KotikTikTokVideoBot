# Котик • TikTok скачать

[Открыть бота](https://t.me/KotikTikTokVideoBot).

Пришли публичную ссылку TikTok: бот получает публикацию через TikWM и отправляет её в личный чат.
Поддерживает полные, мобильные и короткие ссылки, а также скрытые ссылки Telegram.
Выбирает HD, если размер позволяет отправить файл. Для крупных файлов или отказа Telegram
показывает кнопку прямого скачивания. Фотографии отправляет альбомами до 10 фото в каждом,
сохраняя порядок. Доступную музыку публикации отправляет отдельным аудиофайлом;
если Telegram не загрузит аудио, выдаёт кнопку скачивания музыки.

В любом чате введи `@KotikTikTokVideoBot ссылка` и выбери видео, отдельное фото или музыку.
Telegram отправляет один выбранный inline-результат за раз. Для всех фотографий есть
кнопка «Весь альбом в боте», которая открывает личку и запускает скачивание публикации.
Inline-результаты поддерживают страницы до 50 элементов. В BotFather включён `/setinline`.

Обработчики и база данных работают на Telegram Serverless. Новые видео передаются Telegram
по URL: до 20 МБ. Повторные загрузки используют сохранённый `file_id` этого бота.
Временное сообщение загрузки удаляется после завершения. На пользователя допускается
одна одновременная загрузка с паузой 3 секунды. Истёкшая блокировка восстанавливается через 2 минуты.
Работоспособность получения новых видео зависит от внешнего сервиса TikWM.
Адреса медиа кешируются в базе на 5 минут, inline-ответы — на 30 секунд.

## Разработка

Установи зависимости командой `npm install`. Для тестов используй `npm test`.
Облачные проверки: `node tests/run-cloud.mjs`; внешние сервисы заменены,
а временные записи базы удаляются после завершения.
Укажи CLI-токен Serverless в переменной `TGCLOUD_TOKEN` и выполни `npm run deploy`.
Применяй предложенные миграции базы данных. Токены не добавляются в репозиторий.

Все комментарии исходного кода написаны на русском языке.
